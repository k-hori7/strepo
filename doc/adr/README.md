# Architecture Decision Records (ADR)

意思決定の背景と理由を記録し、将来の参照に役立てる。

## テンプレート

```markdown
# ADR-XXX: タイトル

## Status
Proposed / Accepted / Deprecated / Superseded

## Context
この決定が必要になった背景・課題。

## Decision
何を決定したか。

## Consequences
この決定による影響（メリット・デメリット）。
```
